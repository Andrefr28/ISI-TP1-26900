Projeto de Análise e Integração de Dados — KNIME

Food Rescue

Utilização de dados para combater o desperdício alimentar e melhorar a distribuição de excedentes para instituições de solidariedade.

1. Tema escolhido

O projeto aborda o combate ao desperdício alimentar, através da criação de um cenário de Food Rescue. A proposta consiste em utilizar o KNIME para integrar dados de supermercados, instituições de solidariedade e voluntários.

Ideia central: transformar dados dispersos em informação útil para decidir que alimentos devem ser recolhidos, para onde podem ser encaminhados e quem poderá efetuar o transporte.

2. Problema

Diariamente podem existir alimentos ainda próprios para consumo que, por diferentes motivos, deixam de ser comercializados. Ao mesmo tempo, existem instituições que necessitam de alimentos e voluntários que podem apoiar a recolha e distribuição.

O problema que pretendo explorar é: como cruzar estes diferentes dados para tornar o processo de redistribuição mais eficiente?

3. Porque escolhi este tema?

Impacto social

Permite relacionar tecnologia e análise de dados com uma necessidade social concreta.

Problema real

O desperdício alimentar e a redistribuição de alimentos são problemas existentes na sociedade.

Bom caso para KNIME

O problema exige integração, limpeza, transformação, filtragem e cruzamento de dados.

Dados heterogéneos

Permite trabalhar diretamente com CSV, JSON e XML, demonstrando diferentes fontes e formatos.

7. Lógica de decisão

O sistema deverá procurar criar correspondências entre os três conjuntos de dados.

Exemplo

Um supermercado possui 30 kg de alimentos com validade próxima. O KNIME identifica o excedente como prioritário e procura uma instituição que aceite esse tipo de alimento. Depois procura um voluntário disponível, com veículo adequado e capacidade suficiente para transportar a quantidade.

Critérios possíveis

  • Estado do excedente = disponível;
  • Data de validade próxima → maior prioridade;
  • Tipo de alimento compatível com a instituição;
  • Instituição localizada preferencialmente na mesma zona;
  • Voluntário disponível;
  • Capacidade de transporte suficiente;
  • Refrigeração quando necessária.

8. Tratamento e análise dos dados

No KNIME pretendo demonstrar várias etapas de processamento:

  • Leitura dos três formatos de ficheiro;
  • Verificação de valores em falta;
  • Conversão de tipos de dados;
  • Normalização de campos;
  • Filtragem por validade e disponibilidade;
  • Criação de colunas calculadas, como prioridade;
  • Junção das diferentes tabelas;
  • Ordenação e seleção das melhores correspondências;
  • Criação de estatísticas e visualizações.

9. Resultados esperados

Alimentos recuperados

Quantidade total e distribuição por categoria.

Prioridades

Identificação dos alimentos cuja validade está mais próxima.

Instituições

Distribuição dos alimentos pelas instituições adequadas.

Logística

Identificação dos voluntários capazes de realizar cada transporte.

10. Indicadores finais

O resultado final poderá apresentar indicadores como:

  • Total de excedentes disponíveis;
  • Total de alimentos recuperáveis;
  • Quantidade por categoria;
  • Número de instituições potencialmente apoiadas;
  • Número de voluntários disponíveis;
  • Número de entregas possíveis;
  • Alimentos com validade crítica;
  • Distribuição geográfica por concelho.

12. Fontes e credibilidade

Para contextualizar o projeto serão utilizadas fontes públicas e institucionais, nomeadamente informação do Banco Alimentar Contra a Fome e informação pública relacionada com instituições sociais.

Os dados de operação diária — quantidades de excedentes, disponibilidade dos voluntários, horários e correspondências — serão simulados, porque o objetivo do trabalho é demonstrar o processamento e análise de dados no KNIME.

  • Banco Alimentar Contra a Fome — informação institucional;
  • Banco Alimentar de Braga — contexto regional;
  • Informação pública da Segurança Social sobre instituições sociais.

13. Justificação final

Porque é que este projeto faz sentido para KNIME?

Porque envolve diferentes fontes e formatos de dados, exige tratamento e integração, contém regras de decisão e permite transformar dados brutos em informação útil para apoiar decisões. Além disso, apresenta uma aplicação prática da análise de dados num problema com impacto social.

14. O que pretendo demonstrar na apresentação

  1. Apresentar o problema do desperdício alimentar;
  2. Explicar a solução proposta;
  3. Mostrar os três ficheiros e os diferentes formatos;
  4. Construir o workflow no KNIME;
  5. Mostrar a transformação e integração dos dados;
  6. Executar o processo de matching;
  7. Apresentar os resultados através de tabelas e gráficos;
  8. Explicar as limitações e possíveis melhorias futuras.
