FOOD RESCUE - DADOS PARA KNIME

CONTEÚDO
- instituicoes.csv: 80 instituições.
- excedentes.json: 300 registos de excedentes alimentares.
- voluntarios.xml: 60 voluntários.

NOTA IMPORTANTE
Este é um dataset académico/simulado. Não deve ser usado para operações reais.
Os nomes e concelhos das instituições foram baseados em listas públicas do Banco Alimentar de Braga.
Moradas, códigos postais simplificados, contactos, capacidades e restantes atributos operacionais
foram gerados/simulados para permitir demonstrações no KNIME sem expor dados pessoais.
